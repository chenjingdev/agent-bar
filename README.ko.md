그 밖에 이런 것도 됩니다.

- **Claude Code에서 쓰기**: 그룹 목록의 Claude 계정에서 **쓰기**를 누르면, 평소 쓰는 `claude`의 로그인이 클릭 한 번에 그 계정으로 바뀝니다. 바꿀 때마다 브라우저로 로그인하지 않아도 됩니다([동작 방식](#claude-code에서-쓰기)).
- 계정의 한도 아래에 **초기화 쿠폰** 수량과 만료일이 표시됩니다. Claude에 주간·Fable 주간처럼 여러 종류가 있으면 **초기화**에서 종류를 고를 수 있고, 쓸 수 없는 종류는 이유가 표시됩니다. **확인**을 누르면 초기화를 요청합니다. Codex는 가장 먼저 만료되는 쿠폰을 씁니다.
- **Antigravity**(실험 기능): 이 맥의 `agy`나 Antigravity 앱에 로그인된 계정 하나를 봅니다.
- 서비스가 알려 주면 Claude의 모델별 주간 한도와 Antigravity의 모델 그룹별 한도도 보여 줍니다.
- 메뉴 막대 그룹에 계정을 개수 제한 없이 넣고(**설정 › 메뉴 막대**의 **이 그룹의 계정**), 그룹을 누르면 그 계정을 모두 목록 한 장으로 봅니다. 줄마다 계정 배지, 요금제, 주소와 5시간·주간 한도가 있고, 서비스가 알려 주면 모델별 주간 한도도 있습니다. 칸마다 %와 초기화까지 남은 시간을 보여 줍니다. 목록 위 **정렬** 단추로 내가 정한 순서(**수동**)로 두거나, **5시간 초기화**·**주간 초기화**가 가까운 계정부터 놓습니다. 그룹마다 고른 것을 기억합니다.
- 그룹에 넣은 계정의 한도 가운데 세 줄까지 골라 메뉴 막대에 보여 줍니다(링 게이지는 한 줄, 텍스트만은 줄 수 제한 없음). 그룹·줄·계정은 끌어다 놓아 순서를 바꿉니다. 그룹 안 계정 순서는 설정의 칩이나 목록의 줄을 끌어 바꿉니다.
- 읽지 못한 값은 0%가 아니라 `--`로 보여 주고, 지난 값을 보여 줄 때는 저장된 값이라고 표시합니다.
- 1, 2, 5, 10분 중 고른 간격으로 새로 고치고, 바로 새로 고칠 수도 있습니다. 그룹에 넣은 계정은 메뉴 막대 줄에 없어도 새로 고칩니다. 서비스마다 한 번에 한 계정씩, 요청 사이를 잠깐 쉬며 고칩니다(Claude 1초, Codex 0.5초). **메뉴 막대에 표시**를 끈 그룹은 건너뜁니다.
- 맥에 로그인할 때 AgentBar를 자동으로 열 수 있습니다.

### Windows <sub>미리보기</sub>

Windows 11(x64)용은 알림 영역(트레이)에 뜨는 작은 판입니다. Claude Code · Codex 계정의 한도, 초기화 시각, 초기화 쿠폰을 보고 Claude Code 계정을 바꿉니다. 그룹 · 모양 바꾸기 · Antigravity와 자동 업데이트는 아직 없습니다.

시작 메뉴에서 PowerShell 창을 열고 아래 한 줄을 붙여 넣어 실행합니다(관리자 권한 없이, 업데이트도 같은 줄). `powershell -Command "…"`처럼 다른 명령에 감싸 돌리면 Microsoft Defender가 막을 수 있습니다.

```powershell
irm https://raw.githubusercontent.com/chenjingdev/agent-bar/main/windows/install.ps1 | iex
```

서명 없는 실행 파일이 하나도 없습니다. Node.js 재단이 서명한 공식 `node.exe`와 읽을 수 있는 스크립트뿐이라 Smart App Control이 켜진 PC에서도 막히지 않습니다. 지울 때는 **설정 › 앱 › 설치된 앱**에서 AgentBar를 제거합니다. 코드와 만드는 법은 [windows/](windows)에 있습니다.

## COMMAND LINE<br>명령으로 다루기

메뉴 막대 패널과 설정에서 하는 일은 모두 터미널 명령으로도 할 수 있습니다. 그래서 Claude Code 같은 AI도 한도를 읽고 AgentBar를 사람처럼 바꿀 수 있습니다. 명령은 AgentBar 프로그램 자신(`AgentBar.app/Contents/MacOS/agent-bar`)입니다. 명령과 함께 실행하면 켜져 있는 AgentBar에 일을 넘기고(데이터 폴더의 `control.sock`, 나만 읽을 수 있음) 답을 출력한 뒤 끝납니다. AgentBar가 꺼져 있으면 먼저 뒤에서 켭니다.

AgentBar는 켜질 때 `~/.local/bin` 폴더가 있고 그 안에 `agentbar`가 없으면 `agentbar`로 링크를 만듭니다. 그렇지 않으면 한 번 실행하세요.

```bash
/Applications/AgentBar.app/Contents/MacOS/agent-bar install-cli            # ~/.local/bin/agentbar
/Applications/AgentBar.app/Contents/MacOS/agent-bar install-cli --dir 폴더  # PATH의 다른 폴더
```

```text
agentbar status [계정]                    모든 계정의 사용량: 한도별 % · 초기화 시각 · 쿠폰
agentbar refresh [계정]                   지금 새로 고치고 결과 보기
agentbar accounts                         계정 순서대로: 번호 · id · 서비스 · 이름 · 상태
agentbar account add claude|codex|antigravity     브라우저 로그인 뒤 등록(로그인은 사람이 마침)
agentbar account reconnect|remove|rename|move <계정> ...
agentbar claude-code                      Claude Code가 쓰는 계정, 준비된 계정
agentbar claude-code setup|use <계정>     Claude Code용으로 한 번 로그인 / Claude Code를 그 계정으로 바꾸기
agentbar resets <계정>                    사용량 초기화 쿠폰, `resets use <계정> [종류] --yes`로 하나 쓰기
agentbar groups                           메뉴 막대 그룹과 그 계정 · 줄
agentbar group add|set|remove|move        이름 · 모양 · 보이기 · 이름 뱃지 · 퍼센트 · 목록 순서
agentbar group account add|remove|move    그룹 패널에 보일 계정
agentbar line add|set|remove|move         사용량 줄: <그룹> <계정> --limit 5h|weekly|fable
agentbar settings [set refresh-interval|language|open-at-login 값]
agentbar update | open [탭] | restart | quit | version | paths
```

`agentbar --help`는 모든 명령을, `agentbar <명령> --help`는 그 명령을 설명합니다. 모든 명령에 `--json`이 있습니다. 계정은 `agentbar accounts`의 번호 · 이름이나 이메일 · id 앞부분, 또는 하나뿐일 때 `claude`/`codex`로, 그룹은 `agentbar groups`의 번호 · 이름 · id 앞부분으로 가리킵니다. 끝 상태는 0 완료, 1 실패, 2 명령 잘못(`--yes` 빠짐 포함), 3 AgentBar에 닿지 못함입니다. 명령은 버튼과 같은 단계를 거치므로 같은 확인이 적용됩니다. 로그인은 여전히 사람이 브라우저에서 마쳐야 하고, 계정 지우기와 쿠폰 쓰기에는 `--yes`가 필요합니다. `AGENTBAR_DATA_DIR`와 `AGENTBAR_DEFAULTS_SUITE`로 띄운 개발 실행에는 같은 변수로 실행한 명령이 닿습니다.

## GETTING STARTED<br>처음 쓰기

AgentBar를 처음 열면 계정이 없으므로 **설정 › 계정**이 열립니다. <b>계정 추가…</b>를 누르고 서비스를 고르세요. 추가하는 서비스마다 공식 명령줄 도구가 있어야 합니다.

| 서비스 | 필요한 것 | 로그인하는 방법 |
|---|---|---|
| Claude | [Claude Code](https://code.claude.com/docs/en/setup) (`claude`) | AgentBar가 그 계정용 폴더를 따로 두고 `claude auth login --claudeai`를 실행해, 브라우저에 Claude 로그인 페이지를 엽니다. |
| Codex | [Codex CLI](https://github.com/openai/codex) (`codex`) | AgentBar가 그 계정용 폴더를 따로 두고 `codex app-server`를 띄워, ChatGPT 로그인 페이지를 엽니다. |
| Antigravity (실험 기능) | 로그인해 둔 [`agy`](https://antigravity.google/cli) | 터미널에서 `agy`를 한 번 실행해 로그인해 두세요. AgentBar는 거기 로그인된 계정을 읽습니다. `agy`가 없으면 Antigravity 앱이 열려 있는 동안 앱에서 읽습니다. |

- 처음 Claude 계정을 추가하기 전에 AgentBar가 Claude 로그인을 어떻게 보관하는지 설명하고 동의를 받습니다([Claude와 Anthropic 약관](#claude와-anthropic-약관) 참고).
- 브라우저에 로그인된 계정 말고 다른 계정을 추가하려면, Claude 승인 페이지에서는 **Switch account**를(claude.ai 로그인도 함께 바뀝니다), ChatGPT 페이지에서는 **Sign in with another account**를 고르세요. AgentBar에서 **비공개 창으로 로그인**을 누르면 평소 브라우저 로그인과 섞이지 않는 비공개 창에서 로그인합니다.
- AgentBar에서 로그인해도 평소 쓰는 `claude`, `codex`의 로그인은 바뀌지 않습니다. **쓰기**를 누를 때만 `claude`의 로그인이 바뀝니다.
- AgentBar는 셸의 `PATH`를 쓰지 않고, 아래 폴더에서 도구를 찾습니다.
  - `claude`: `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`, `~/.bun/bin`
  - `codex`: `/opt/homebrew/bin`, `/usr/local/bin`, `~/.bun/bin`
  - `agy`: `~/.local/bin` (또는 `/Applications`에 있는 Antigravity 앱)
- AgentBar는 이 도구들을 `/usr/bin/python3`로 실행합니다. `/usr/bin/python3`는 Xcode Command Line Tools(`xcode-select --install`)에 들어 있습니다.

그다음 **설정 › 메뉴 막대**에서 그룹을 만들고, **이 그룹의 계정**에 계정을 넣고, 모양을 고르고, 그룹마다 보여 줄 한도를 정합니다. 메뉴 막대의 그룹을 누르면 그 그룹의 계정이 목록 한 장으로 나옵니다. 응용 프로그램 폴더에서 AgentBar를 다시 열면 설정 창이 다시 열립니다.

## HOW IT WORKS AND PRIVACY<br>동작 방식과 개인정보

AgentBar에는 서버가 없고, AgentBar에 따로 가입할 필요도 없습니다. 이 맥에 저장된 로그인 정보를 읽어 각 서비스에 직접 묻습니다.

- **로그인 정보.** 추가한 계정마다 `~/.agentbar/multi-account-v1/` 안에 내 macOS 사용자만 읽을 수 있는 폴더가 생기고, AgentBar는 거기 둔 로그인 정보를 읽습니다. 평소 쓰는 `claude`, `codex`, `agy`의 로그인을 가져오거나 바꾸지 않습니다. 다만 **쓰기**를 누르면 `claude`의 로그인을 바꿉니다([아래](#claude-code에서-쓰기) 참고). 설정에서 계정을 지우면 그 계정의 로그인 정보와 저장된 사용량도 지워집니다.
- **Claude.** AgentBar가 관리하는 계정의 토큰으로 Anthropic OAuth 사용량 API(`api.anthropic.com/api/oauth/usage`)를 호출합니다. 로그인 뒤 키체인의 로그인 정보를 계정 폴더에 복사하고 필요할 때 그 폴더의 토큰을 갱신합니다. 갱신 요청(`POST platform.claude.com/v1/oauth/token`)은 Claude Code가 자기 로그인을 갱신할 때와 같은 모양으로 보냅니다: Claude Code의 클라이언트 ID, 이미 받은 권한 범위, 그리고 Claude Code가 이때 쓰는 HTTP 클라이언트의 헤더(`User-Agent: axios/1.15.2`, `Accept: application/json, text/plain, */*`). 그 밖의 Claude 요청은 agent-bar처럼 사용량 조회 · 쿠폰 조회 · 쿠폰 사용 요청 모두에 `User-Agent: claude-cli/<설치된 버전> (external, cli)`를 보냅니다. 버전은 AgentBar가 켜질 때 `claude --version`으로 읽고, Claude Code가 너무 오래됐거나 버전을 못 읽으면 쿠폰 프로그램이 받는 가장 낮은 버전인 2.1.295를 씁니다. 30분쯤마다 사용량 조회에 `cedar_ember=1&skip_spend=1`을 붙여 쿠폰도 함께 묻고, Claude가 이 표시를 거절하면 표시 없이 사용량만 읽은 뒤 5분 뒤에 쿠폰을 다시 묻습니다. **확인**을 누르면 고른 쿠폰을 확인하려고 쿠폰을 한 번 더 읽고(바로 앞 조회에 이어져 거절되면 확인 없이 진행), `POST api.anthropic.com/api/organizations/<조직>/reset_rate_limits`로 사용 요청을 보냅니다. `request_id`는 소문자로 씁니다. 쿠폰 인터페이스는 공개 문서에 없습니다.
- **Codex.** 공식 `codex app-server`(`account/read`, `account/rateLimits/read`)로 읽습니다. 초기화 쿠폰에서 **확인**을 눌렀을 때만 `account/rateLimitResetCredit/consume`을 부릅니다. 계정마다 `CODEX_HOME`을 따로 두고 띄우며, 네트워크 요청은 Codex CLI가 합니다.
- **Antigravity.** Antigravity 로그인 정보는 AgentBar가 갖고 있지 않습니다. AgentBar는 `agy -p /usage`를 실행해 읽는데, 이 명령은 모델을 돌리지 않고 한도 보고만 출력하므로 한도를 쓰지 않습니다. 터미널 없이, 브라우저를 열 수 없는 상태로 실행하므로 `agy`가 로그인되어 있지 않으면 바로 멈추고 계정에 로그인하라는 안내가 뜹니다. `agy`가 없으면 Antigravity 앱이 열려 있는 동안 앱의 로컬 서버(`127.0.0.1`)에 묻습니다.
- **따로 보내는 정보는 없습니다.** 분석 도구나 사용 통계 수집도 없습니다. 업데이트는 GitHub 릴리스의 `appcast.xml`로만 확인하고 거기서 받습니다.

### Claude Code에서 쓰기

그룹 목록의 Claude 계정 줄에서 **쓰기**(줄에 마우스를 올리면 보입니다)를 누르면, 평소 쓰는 `claude`의 로그인(기본 로그인, 키체인 항목 `Claude Code-credentials`)이 그 계정으로 바뀝니다. 모든 Claude Code 세션이 그 계정을 쓰게 되고, 열려 있는 세션도 30초쯤 안에 바뀝니다. Remote Control 연결은 끊깁니다. Claude Code가 지금 쓰는 계정에는 **사용 중**이 보입니다.

- **계정마다 한 번 준비합니다.** **설정 › 계정**에서 <b>준비하기…</b>를 누르면 Claude Code가 브라우저로 그 계정에 로그인해 계정 전용 폴더(`~/.agentbar/multi-account-v1/lend/<계정 ID>/`)에 저장합니다. AgentBar가 사용량을 읽는 로그인과는 따로라서, 계정을 바꿔도 사용량 표시는 멈추지 않습니다.
- **로그인은 Claude Code만 씁니다.** AgentBar는 그 계정의 리프레시 토큰을 `CLAUDE_CODE_OAUTH_REFRESH_TOKEN`([Claude Code 환경 변수](https://code.claude.com/docs/en/env-vars))에 넣어 `claude auth login`을 실행하고, 이때 키체인 항목은 `/usr/bin/security`로만 읽습니다. 그래서 키체인 허락 창이 뜨지 않습니다.
- **리프레시 토큰은 한 번만 씁니다.** 로그인을 넘기면 그 토큰은 다 쓴 것이 되므로, 같은 토큰을 두 번 넘기지 않습니다. Claude Code에 있던 로그인은 원래 계정 몫으로 돌려받아서, 다시 돌아갈 때도 브라우저가 뜨지 않습니다. 바꾸는 사이에 열린 세션이 그 로그인을 갱신하면, 그 계정은 한 번 더 준비합니다.
- **바꾼 뒤 확인합니다.** 바꾼 뒤 Claude Code 로그인을 다시 읽어, 고른 계정이 아니면 알려 줍니다. Claude Code가 AgentBar에 없는 계정으로 로그인되어 있으면, 바꾸는 순간 그 로그인이 Claude Code에서 사라지므로 먼저 묻습니다. 바꾸는 중에 종료하면 바꾸기가 끝날 때까지(최대 90초) 기다립니다. 그래도 중간에 꺼지면 다음에 켤 때 마저 끝내거나 되돌립니다.
- **볼 때만 읽습니다.** **사용 중**을 보이려고, 패널이나 **설정 › 계정**을 열 때와 새로 고침을 누를 때 Claude Code가 어느 계정을 쓰는지 확인합니다. 키체인 항목이 있는지만 보고(토큰은 읽지 않음) `~/.claude.json`의 계정을 읽습니다. 주기적인 새로 고침에서는 읽지 않아서, 자리를 비운 사이 키체인 창이 뜰 일이 없습니다.
- **기록에는 토큰을 남기지 않습니다.** 바꿀 때마다 `~/.agentbar/multi-account-v1/logs/claude-code-switch.log`에 남깁니다(**기록 열기**).
- Claude Code 2.1.309 이상이 필요합니다. 계정을 지우면 Claude Code용으로 저장한 로그인도 지우고, Claude Code의 로그인은 그대로 둡니다. 앱으로 실행할 때만 켜집니다. `swift run`이나 `AGENTBAR_DATA_DIR`·`AGENTBAR_DEFAULTS_SUITE`를 준 개발용 실행에서는 꺼집니다.

### Claude와 Anthropic 약관

Anthropic의 [Claude Code 약관](https://code.claude.com/docs/en/legal-and-compliance)은 Claude 로그인을 보관하는 앱을 제한합니다. 그래서 Anthropic이 언제든 이 방식을 막을 수 있습니다. AgentBar는 처음 Claude 계정을 추가하기 전에 이 점을 알리고 한 번 동의를 받습니다. Anthropic이 막으면 다시 연결해도 소용이 없으므로, 다시 연결하라고 하지 않고 막혔다고 알려 줍니다. **쓰기**는 누를 때만, 직접 로그인한 내 계정끼리만 바꿉니다. 한도에 닿았다고 저절로 바꾸지는 않습니다. Claude 초기화 쿠폰은 같은 API의 공개되지 않은 부분을 쓰므로 언제든 안 될 수 있고, AgentBar는 **확인**을 눌렀을 때만 쿠폰을 씁니다.

### Antigravity와 Google 약관

Google의 [Antigravity 약관](https://antigravity.google/terms)은 다른 소프트웨어가 Antigravity 로그인을 쓰지 못하게 합니다. 그래서 AgentBar는 로그인 정보를 쓰지 않고 `agy`나 앱에 묻습니다. 둘 다 문서로 공개된 방식이 아니어서, Antigravity가 업데이트되면 멈출 수 있습니다.
